# Domínios Ricos

## Linguagem Ubíqua

É a linguagem compartilhada pelo projeto entre os desenvolvedores
e o cliente. Será responsável por nivelar o conhecimento entre ambos
e ajudar no decorrer do projeto. Dominar esse conhecimento será essencial
para o resultado do projeto.

- Trazer os jargões da realidade do cliente para o projeto.

## Domínios Ricos e Anêmicos

Os domínios podem ser ricos em regras de negócio ou anêmicos, 
deixando as decisões para algo externo como um banco de dados por exemplo.

## Sub Domínios

São quebras de domínios grandes em menores para melhor
manutenção e organização do projeto.

## Separação de Contextos Delimitados

Separação de partes do sistemas para desempenhar 
funções específicas de forma isoladas e funcionamento próprio.
